✅ Phase 4 — Immediate Builds — ALL COMPLETE
Completed June 2026
✅ Emil Kowalski Skill
UI polish enforcement installed globally. Every component we build is now reviewed against his animation, easing, timing, and taste standards automatically.
✅ Competitor Intelligence — Per Platform
User inputs 2-3 competitors per platform (Instagram/TikTok/LinkedIn/etc) and pastes their top hooks. Claude extracts niche patterns — hook style, emotional triggers, content format, hashtag strategy — calibrated specifically to each platform. Stored as niche_intelligence (per-platform JSON) on brand record. Never copies content — learns principles only.
✅ Niche-Calibrated Generation
Per-platform niche_intelligence fed into generate-posts prompt. Instagram variations get Instagram niche calibration. LinkedIn gets LinkedIn calibration. Same brand, platform-optimised hooks. 100% original — one level better than competitors.
✅ Virality Gate (Silent Quality Filter)
Runs after every generation batch. Claude scores every hook 0–100. Anything scoring below 70 is auto-rewritten before saving to Supabase. Users only ever see the strongest version. Non-fatal — falls back to original if it errors. Adds ~2-3s to pipeline, invisible to users.
✅ Flux.1-schnell — Replaced DALL-E
DALL-E fully removed from both generate-images and generate-single-image routes. Replaced with Flux.1-schnell via Together.ai. $0.003/image vs $0.04–0.08 with DALL-E — 13x cheaper. API key live on Vercel. Together.ai account connected.

🔬 Tools Researched — Decisions Log
Evaluated June 2026 — What We Chose and Why
✅ Together.ai + Flux.1-schnell
CHOSEN — replacing DALL-E. Apache 2.0 license. $0.003/image (13x cheaper). Black Forest Labs — serious credentialled team. Privacy: Together.ai does not train on API requests. Enterprise-safe. $5 deposit to unlock, startup program for $50K credits.
✅ LTX Studio Standard — Phase 5 Video
CHOSEN — Phase 5 launch video engine. $35/month subscription. Commercial rights included. LTX-2.3-fast model. 5-sec 9:16 portrait, native audio. ~$0.03/video. Simple API — no infrastructure. Toggle gated OFF during testing (ENABLE_VIDEO_GENERATION=false). Endpoint: /api/generate-video live on Vercel.
✅ Wan2GP by deepbeepmeep — Phase 6
CHOSEN — Phase 6 scale migration. By Wassim Younes (@deepbeepmeep). Runs Wan 2.6 + LTX-2 locally. Self-hosted on RunPod GPU ($0.34/hr). $0.006/video — effectively free. At 100 users: $7.20/month total. Fully private (data never leaves server). Apache 2.0. 6GB VRAM minimum. Mac M4 support (experimental).
❌ OpenMontage
DROPPED — redundant. LTX Studio already covers the full production pipeline: script → storyboard → keyframe animation → sound → timeline → ad/trailer/music video output. OpenMontage adds nothing we don't already have at $35/month.
✅ Emil Kowalski Skill
CHOSEN + INSTALLED. Free Claude Code skill. Encodes UI polish philosophy — animations, easing, taste. All components built from now on reviewed against his standards. From github.com/emilkowalski/skill.
✅ Higgsfield Virality Predictor
CONCEPT ADOPTED — built in-house. Higgsfield's commercial virality predictor inspired our silent virality gate. We built our own version using Claude instead of paying Higgsfield. Scores hooks 0–100, rewrites anything below 70 before saving.
❌ DALL-E (OpenAI)
REPLACED by Flux.1-schnell. Was: $0.04–0.08/image. Replaced with Flux.1-schnell at $0.003/image. 13x cost saving. Better quality for social media brand imagery. Both generate-images and generate-single-image routes updated.
❌ Higgsfield.ai (commercial)
DROPPED — paid platform, misleading "free" claims. Starts at $9/month, barely 2-3 quality videos. No free tier. The "free Higgsfield" creators talk about is Open Generative AI (Anil-matcha's repo) — a separate open-source alternative. Higgsfield CLI connects to their paid API, not a free model. Replaced by LTX Studio Standard + Wan2GP.
❌ Open Generative AI via muapi.ai
DROPPED for production — privacy concern. Platform (Anil-matcha repo) is MIT licensed and free. BUT premium models (Kling, Veo, Sora) route through muapi.ai servers — brand data leaves our control. Not acceptable for a SaaS serving business brands. Good for personal use only. Use Wan2GP self-hosted instead for full privacy.
❌ OpenArt ($14.50/month)
EVALUATED — dropped for privacy. Multi-model platform (Kling, Veo, Wan, LTX, 100+ models). $14.50/month annual = 150 videos = $0.097/video. Great value BUT brand data goes through OpenArt's servers. Not acceptable for commercial SaaS. LTX Studio Standard wins on both cost and data control.
⏸️ SkyReels V4
EVALUATED — deferred as future option. Best for human-centric video (coaches, fitness, personal brands). 33 facial expressions, 400+ natural movements. Hollywood-trained. Joint audio+video. Apache 2.0. $0.30/video via piapi.ai or self-hosted free. Consider adding as premium option in Phase 7 for brands featuring real people.
❌ Uncensored.com
DROPPED — privacy risk. "No content filters" platform. No GDPR compliance clarity. No enterprise data handling guarantees. Not suitable for a SaaS serving business clients. Site also unreachable during evaluation.
❌ GodMod3.ai
DROPPED — wrong tool type. Browser-based chat interface, not a developer API. Solo developer maintainer (risk). The useful insight: it uses OpenRouter — which we noted as a future cost-saving option for LLM calls.
❌ BigCreator.in
DROPPED — no API. Indian content creator tool. No developer API to integrate. Paid only (₹999–₹2,499/month). Built for Hindi/Hinglish creators specifically. We're building better natively.
❌ Poe
DROPPED — consumer app only. No developer API. Consumer chat aggregator. Doesn't reduce costs or add features to the platform.
❌ Vulk.dev
DROPPED — not relevant. Tool for developers to deploy full-stack apps. We already have Vercel + Supabase. Adds nothing to user experience.
⏸️ Nvidia NIM
DEFERRED — kept as backup. Enterprise-grade free AI APIs. Very safe and private ($3T company). Good fallback if Together.ai has downtime. Will add as secondary image generation option in Phase 5.
⏸️ OpenRouter (via GodMod3 insight)
NOTED — future cost saving. Discovered via GodMod3 research. OpenRouter provides free Llama, Mistral, DeepSeek models via one API. Could replace Claude for non-critical tasks (hashtags, captions) to reduce LLM costs. Revisit in Phase 6.
